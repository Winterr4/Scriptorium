# Scriptorium
Scriptorium is a self-study app built for independent learners. It runs as an installable web app (PWA) on iPhone, with a dark academia aesthetic designed to make long study sessions feel calm and focused.
 
## Key Features
 
- **Study areas:** Separate spaces for each subject (e.g., English, Psychology) with independent progress, plus a global statistics view.
- **Spaced repetition:** Anki-style flashcard decks that schedule reviews for long-term retention.
- **Statistics:** Progress and consistency tracking across all areas.
- **Kanban board:** Organize topics and tasks by status.
- **Focus mode:** Distraction-free study sessions.
- **Accounts and cloud sync:** Sign in and keep your data across devices (by Supabase).
- **Deployment**: it can be deployed to Netlify with free HTTPS hosting and a public URL that can be installed on iPhone as a PWA.
